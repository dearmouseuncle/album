# 🐘 小象相册

本地备份相册并快速整理你的回忆 — 订阅多个文件夹，网页浏览、筛选、批量清理，把散落在各处的照片和视频集中管理。

## 功能

- **多目录订阅** — 像添加订阅源一样添加多个照片文件夹，统一浏览
- **缩略图** — 自动预生成缓存 + 懒加载，支持 HEIC/HEIF
- **视频流** — HTTP Range 支持拖拽进度条
- **筛选** — 年月、图片/视频类型
- **排序** — 时间 / 大小 / 名称，正序倒序
- **快速清理** — 全屏逐张过，↑删除 ↓保留 Esc退出
- **划过选择** — 按住鼠标划过多张批量选中
- **零数据库** — 纯文件扫描，不改动原图
- **回收站** — 删除进回收站，可恢复

## 快速开始

### 方式一：下载 EXE（推荐）

从 [Releases](https://github.com/dearmouseuncle/album/releases) 下载 `小象相册.exe`，双击运行。

### 方式二：双击启动

```
双击 启动.bat
```

### 方式三：Python 运行

```bash
pip install -r requirements.txt
python album.py
```

浏览器自动打开 `http://127.0.0.1:18899`

## 使用说明

### 添加相册目录（订阅）

1. 点击右上角 **「设置」**
2. 点 **「选择文件夹」** 或手动输入路径，点 **「添加」**
3. 点 **「保存并扫描」**

就像 RSS 订阅一样，可以随时添加/移除文件夹。支持本地磁盘和网络路径。

### 快速清理

适合从大量照片里挑掉废片：

1. 点击 **「快速清理」** 按钮（或在光箱里点「快速清理」从当前张开始）
2. **↑** 键删除当前张
3. **↓** 键保留，看下一张
4. **Esc** 退出

### 快捷键

| 键 | 作用 |
|---|---|
| ← → | 上一张 / 下一张 |
| Delete | 删除当前选中 |
| Esc | 关闭光箱 / 设置 |

## 打包成 EXE

```bash
pip install pyinstaller
build.bat
```

生成 `dist/小象相册.exe`，单文件包含所有依赖。

> **视频缩略图** 需要 [ffmpeg](https://ffmpeg.org/download.html) 在 PATH 里，没有也能用，只是视频不显示封面。

## 配置

`config.json` 与程序同目录，保存订阅目录：

```json
{
  "dirs": ["D:\\Photos", "E:\\手机备份"],
  "port": 18899
}
```

## 目录结构

```
album/
├── album.py          # 主程序（单文件全栈）
├── 启动.bat           # Windows 启动脚本
├── build.bat         # 打包 exe 脚本
├── requirements.txt  # Python 依赖
├── config.json       # 订阅目录配置（自动生成）
├── thumbs/           # 缩略图缓存（自动生成）
└── trash/            # 回收站（自动生成）
```

## 系统要求

- Windows 10/11（其他系统也能跑，启动脚本是 Windows 的）
- Python 3.9+ 或使用打包好的 EXE
- 浏览器（Chrome/Edge）
