# 合集相册管理器

本地照片/视频管理工具。订阅多个文件夹，网页浏览、筛选、批量清理。

## 功能

- **多目录订阅** — 像添加订阅源一样添加多个照片文件夹
- **缩略图** — 自动预生成缓存，支持 HEIC/HEIF
- **视频流** — HTTP Range 支持拖拽进度条
- **筛选** — 年月、图片/视频类型
- **排序** — 时间 / 大小 / 名称
- **快速清理** — 全屏逐张过，↑删除 ↓保留 Esc退出
- **批量删除** — 拖拽框选，全部进回收站可恢复
- **零数据库** — 纯文件扫描，不改动原图

## 快速开始

### 方式一：双击启动（推荐）

```
双击 启动.bat
```

### 方式二：Python 运行

```bash
pip install -r requirements.txt
python album.py
```

浏览器自动打开 `http://127.0.0.1:18899`

## 使用说明

### 添加相册目录（订阅）

1. 点击右上角 **「设置」**
2. 输入文件夹路径，点 **「添加」**
   - 例如 `D:\Photos`、`E:\手机备份`
   - 也可以添加多个，每个都会被扫描
3. 点 **「保存并扫描」**

就像 RSS 订阅一样，可以随时添加/移除文件夹。

### 快速清理

适合从大量照片里挑掉废片：

1. 点击 **「快速清理」** 按钮（或在光箱里点「快速清理」从当前张开始）
2. **↑** 键删除当前张
3. **↓** 键保留，看下一张
4. **Esc** 退出

### 其他快捷键

| 键 | 作用 |
|---|---|
| ← → | 上一张 / 下一张 |
| Delete | 删除当前选中 |
| Esc | 关闭光箱 / 设置 |

## 打包成 EXE

```bash
pip install pyinstaller
build.bat
```

生成 `dist/Album.exe`，单文件包含所有依赖（Python + Pillow + pillow-heif）。

> **视频缩略图** 需要 [ffmpeg](https://ffmpeg.org/download.html) 在 PATH 里，没有也能用，只是视频不显示封面。

## 配置

`config.json` 与程序同目录，保存订阅目录：

```json
{
  "dirs": ["D:\\Photos", "E:\\手机备份"],
  "port": 18899
}
```

## 目录结构

```
album/
├── album.py          # 主程序（单文件全栈）
├── 启动.bat           # Windows 启动脚本
├── build.bat         # 打包 exe 脚本
├── requirements.txt  # Python 依赖
├── config.json       # 订阅目录配置（自动生成）
├── thumbs/           # 缩略图缓存（自动生成）
└── trash/            # 回收站（自动生成）
```

## 系统要求

- Windows 10/11（其他系统也能跑，启动脚本是 Windows 的）
- Python 3.9+ 或使用打包好的 EXE
- 浏览器（Chrome/Edge）
